# Saif Shafique Digital Portfolio

Hand-coded personal portfolio for the Web App Development module (CRN 59135), University of Salford.

## Pages
1. `index.html` - Home, professional summary
2. `skills.html` - Qualifications, work experience, digital skills
3. `showcase.html` - Business Showcase, four projects plus the development rationale
4. `solution.html` - Problem-Solving Page, Aurum restaurant digital transformation case study
5. `contact.html` - Contact details and professional profiles

## Structure
```
css/style.css      single external stylesheet
js/main.js         shared behaviour (nav, animations, cookie banner)
js/restaurant.js   menu tabs, loyalty demo, form validation, email generation
images/            hand-made SVG graphics
```

## Technologies
HTML5, CSS3 (Grid, Flexbox, custom properties, media queries) and vanilla JavaScript. No frameworks or site builders.

## Validation and testing
- All pages pass the W3C Nu HTML validator and the W3C CSS validator
- Tested at mobile (390px), tablet (768px) and desktop (1366px) widths
- Internal links and images checked
